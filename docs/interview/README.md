# YayaMind 面试材料索引

这个目录用于 AI 产品经理面试准备。建议阅读顺序：

1. [01-PRD.md](01-PRD.md)：先掌握产品背景、用户、痛点、功能范围和后续路线。
2. [02-SDD.md](02-SDD.md)：再理解开发设计、技术栈、模块拆解和核心数据流。
3. [04-PROJECT_DETAILS.md](04-PROJECT_DETAILS.md)：重点阅读，用来回答“项目怎么搭建、前后端怎么连、数据怎么流”。
4. [03-COMPETITOR_ANALYSIS.md](03-COMPETITOR_ANALYSIS.md)：准备竞品和差异化问题。
5. [05-INTERVIEW_QA.md](05-INTERVIEW_QA.md)：最后用于背诵和模拟问答。

推荐面试讲解主线：

> 产品痛点 -> MVP 范围 -> 前后端架构 -> 自然语言数据流 -> AI 与规则边界 -> 关键迭代 -> 竞品差异 -> 下一步规划。
