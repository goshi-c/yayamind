# YayaMind 功能说明

## 已完成能力

- 一周安排：自然周周一到周日，过去日期置灰，今天使用主题色突出。
- 日期详情：点击日期后在右侧显示该日具体安排；选中今天时显示未处理提醒和执行记录。
- 自然语言写入：支持日程、任务、提醒、工作状态、进度和复盘记录。
- 冲突确认：时间重叠、疑似重复、时间不明确、计划过载会触发轻量方案。
- 提醒处理：到点提醒、小猫气泡、浏览器通知、完成、稍后、忽略。
- 阶段性目标：支持创建目标，并更新进行中、暂停、完成、取消等状态。
- 个人画像：根据任务和执行记录生成时间习惯、估时模式、生活节奏和工作偏好雏形。
- Markdown 总结：生成每日或每周总结，写入本地 summaries 目录。
- 布偶猫浮窗：原创动画风格头像，支持拖动、输入和即时反馈。

## 数据闭环

输入不是只停留在页面状态，而是写入本地文件：

- `events.jsonl`：日程和时间块。
- `tasks.jsonl`：任务。
- `work_logs.jsonl`：执行状态和进度。
- `reviews.jsonl`：复盘。
- `reminders.jsonl`：生活提醒。
- `goals.json`：阶段性目标。
- `profiles.json`：个人画像雏形。
- `summaries/*.md`：每日/每周总结。
