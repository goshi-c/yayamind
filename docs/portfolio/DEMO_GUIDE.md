# YayaMind 演示脚本

## 启动方式

```bash
npm install
npm run dev
```

默认访问：

- Web 前端：`http://localhost:5173`
- 本地 API：`http://localhost:8787`

## 推荐演示顺序

1. 打开工作台，展示左侧导航、一周安排、右侧日期详情和布偶猫浮窗。
2. 点击周一到周日的不同列，展示右侧会切换成对应日期的具体安排。
3. 在小猫输入框输入：`今天下午4点开产品复盘会`
4. 展示新日程写入后出现在今天的时间轴里。
5. 输入：`今天下午4点到5点写周报`
6. 展示冲突确认方案，并选择“两个都保留”，说明重叠时间块会并列显示。
7. 输入：`提醒我10分钟后喝水`
8. 展示提醒进入本地数据；到点后小猫气泡提醒，并可在右侧完成、稍后或忽略。
9. 切到“目标”，新增一个阶段性目标，例如：`完成个人助手 MVP`
10. 切到“画像”，展示系统基于执行记录生成的初步习惯信号。
11. 切到“总结”，点击“生成今日总结”，展示 Markdown 总结写入 `personal-assistant-data/summaries/`。

## 讲解重点

- 本地优先：真实个人数据只写入本机的 `personal-assistant-data/`，目录已加入 `.gitignore`。
- 不是静态 mock：自然语言输入会经过后端解析并写入本地文件。
- 冲突不是自动覆盖：时间重叠、模糊时间、任务过载会先给用户确认方案。
- 可迁移性：当前是 Web MVP，后续可以迁移到 Electron/Tauri 桌面壳。
