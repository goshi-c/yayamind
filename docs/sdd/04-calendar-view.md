# 04 日历视图 SDD

## 目标

日历视图是 Web 面板中间区域，用来展示未来 7-10 天的安排。第一版重点是让用户一眼看出每天从早到晚的计划、当前时间、已过去时间，以及不同类型事项的分布。

日历视图不负责复杂排程决策，只负责把 `events.jsonl`、`tasks.jsonl`、`reminders.jsonl` 中和时间相关的数据清晰展示出来。

## 核心布局

第一版采用列式日历：

```text
左侧时间轴 + 未来 7 天日期列
```

默认展示 7 天，后续可以通过 `settings.json` 的 `ui.calendarDays` 扩展到 10 天。

每一天是一列，从早到晚纵向排列。默认时间范围使用：

```text
dayStartHour = 7
dayEndHour = 24
```

如果当天存在更早或更晚的事项，页面可以临时扩展当天可见范围，但第一版不做复杂自适应算法。

## 数据来源

主要读取：

- `events.jsonl`：有明确时间的日程、任务时间块、生活事项。
- `tasks.jsonl`：有 `dueAt` 但未安排时间块的任务。
- `reminders.jsonl`：有 `remindAt` 的提醒。

关系：

- 日历主视图优先展示 `events.jsonl`。
- 有截止时间但没有安排时间块的任务，可以在当天顶部或底部作为待安排任务提示。
- 提醒不占用大块时间，只用小标记或列表提示。

## 事项类型

第一版沿用 `events.jsonl` 的 `type`：

- `meeting`：会议日程。
- `task_block`：任务时间块。
- `life`：生活杂事。
- `exercise`：运动训练。
- `meal`：吃饭。
- `rest`：休息。
- `risk`：风险或延期事项。
- `other`：其他。

视觉上需要明显区分，但不要做得太花。颜色用于帮助扫描，不承担复杂语义。

建议颜色方向：

```text
meeting：蓝色系
task_block：绿色系
life：黄色系
exercise：红/珊瑚色系
meal：橙色系
rest：浅灰或浅紫
risk：红色强调
other：中性灰
```

具体颜色值留到 UI 实现时根据整体视觉再定。

## 当前时间与过去时间

今天这一列需要展示当前时间线。

规则：

- 当前时间线只显示在今天。
- 已过去的时间区域显示为灰色或降低透明度。
- 未来日期不显示过去时间遮罩。
- 过去日期整列可以整体弱化。

当前时间线用于帮助用户判断“现在计划进行到哪里”，不需要承担提醒功能。

## 任务与日程展示

### 有明确开始和结束时间

展示为日历块：

```text
10:00-11:00 项目沟通会
20:00-22:00 写产品方案
```

块高度根据持续时间估算，第一版可以采用简化比例，不要求像专业日历一样精确到分钟。

### 只有截止时间的任务

不直接塞进时间轴，避免误以为已经安排。

展示方式：

- 在对应日期列的“待安排”区域显示。
- 或在右侧今日面板中显示为今日待办。

### 跨天事项

第一版只做简单展示：

- 如果跨天较少，拆到对应日期显示。
- 不做复杂多日横条。

## 交互

第一版需要支持基础查看：

- 点击日历块，右侧今日面板或浮层展示详情。
- 点击空白时间段，可以作为后续添加时间块入口。
- 点击未安排任务，可以引导用户安排时间。

第一版不要求实现拖拽改期。动态重排由 `06-conflict-reschedule.md` 定义，用户确认后再更新日历。

## 空状态

如果某天没有安排：

- 不用大面积提示文案。
- 保持清爽空列。
- 可以轻量显示“暂无安排”或留白。

空状态不应该比已有计划更抢眼。

## 与页面状态的关系

日历视图读取 `03-page-state.md` 中的状态，但不直接管理状态。

关联规则：

- `working`：当前工作如果有关联事件，可以在日历块上显示进行中状态。
- `paused`：当前工作块可显示暂停标记。
- `confirming`：需要确认的时间块不直接写入正式日历，可以显示为临时候选。
- `reminding`：提醒触发时，日历不强打断，主要由右侧今日面板承接。

## 第一版不做

- 不做复杂拖拽排程。
- 不做多人日历。
- 不做外部日历同步。
- 不做复杂跨天横条。
- 不做自动压缩/避让重叠事件的高级布局。
- 不做手机端精细适配，先保证桌面 Web 面板可用。

## 验收标准

- 可以展示未来 7 天的列式日历。
- 今天有当前时间线。
- 过去时间区域会弱化显示。
- 不同类型事件有清晰视觉区分。
- 有时间块的任务和普通日程能展示在正确日期和时间段。
- 未安排任务不会被误展示成已安排时间块。
- 日历能和右侧今日面板共享同一份数据理解。
